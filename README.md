# Laboratorio 07 Diseño de un entorno

**Curso:** Desarrollo de Soluciones en la Nube  
**Estudiante:** Ortiz

## Objetivo

Desarrollar una aplicación con inicio de sesión y CRUD de productos,
y comprobar su funcionamiento mediante balanceo de carga.

## Tecnologías previstas

Node.js, Express, PostgreSQL, Docker Compose, Nginx y AWS.

## Organización

- `app/`: aplicación con autenticación y CRUD.
- `infra/nginx/`: configuración del balanceador local.
- `infra/aws/`: configuración y scripts de despliegue.
- `evidencias/`: capturas finales de las pruebas realizadas.

## Estado

Repositorio inicializado. Implementación y validaciones pendientes.
